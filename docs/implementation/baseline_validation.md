## 口径与条件

- 先累计整个数据集的交集/预测数/真值数，再计算IoU。排除empty17，区分unknown255；standard对无真值但有假阳性的类别记0，两边均无的类别不参与均值；legacy保留原无真值类别记1的规则。
- pooled列跨未来6时刻累计计数；逐时刻均值先计算每个时刻、再平均6时刻，两列不能混写。camera-mask与unmasked也不能直接混用。
- EMA分区、NFE10、seed2026、float32、batch8、decodechunk8；两模型按同一scene/window身份使用相同初始噪声。每次启动哈希验证latent/trajectory/GT/checkpoint，原子保存计数，可断点续跑。
- 原始每帧轨迹条件是该帧到下一帧的真实ego位移。history条件的最后一项已包含当前到下一帧的信息；future还包含未来帧的真实位移，可能覆盖最后目标帧的下一步。因此这里只是带真实动作条件的预测，不是无未来信息的实际规划。
-4219个窗口有重叠；这不是4219个独立样本，没有据此宣称统计显著性。缓存较官方原始数据每场景少一个末帧，保留兼容口径；研究标签另含完整34149帧。
- 两GPU虽分开评测，但同期间有CPU/编码/梯度检查任务；耗时只用于工程进度，不能作为隔离的实时性或公平速度实验。
