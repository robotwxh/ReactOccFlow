# ReactOccFlow工作记录

记录范围：2026年10月26日至11月18日。依据本机可读取的项目聊天记录，并与实施文档、训练及评测产物交叉核对；正文约1000字。

本阶段，我围绕自动驾驶占据世界模型ReactOccFlow，推进了文献调研、方案设计、独立开发、模型训练和实验分析，逐步建立以自车轨迹为条件、联合预测未来语义占据与周围交通参与者状态的研究框架。

在文献与选题方面，梳理Flow Matching、DiT及驾驶世界模型相关研究，对比DOME、OccFM、IR-WM和OccWAM，整理约30篇方案参考文献，形成科学问题说明、实施计划、基线实验方案及ICCV投稿修改建议，明确交互一致性和风险校准的研究目标。

在工程建设方面，创建独立ReactOccFlow环境和代码包，从参考项目复制必要实现，记录来源与校验信息，保持参考仓库只读。建立配置、测试、权重归档与隔离安装流程，完成双卡训练、暂停续训和完整状态恢复验证，保留各阶段实验结果。

在数据准备方面，整理nuScenes与Occ3D的850个场景、34149帧数据，建立训练、调参、校准预留和验证划分；统一当前自车坐标系，生成占据潜变量缓存。交通参与者由当前及历史标注选择和编码，未来状态仅用于监督，并完成坐标、时间、可见性与数据完整性检查。

在模型开发方面，完成冻结OccFM Swin-VAE与交通参与者历史编码的接入，实现占据和参与者双向注意力交互、联合流匹配及一致性约束。先后训练U形CFM与标准DiT，定位到DiT256存在维度瓶颈，扩展至512维，并增加自由生成和分项损失监控。

在完整评测方面，完成官方150场景、4219个预测窗口的测试。U形CFM＋actor平均mIoU为28.67%，其中3秒为24.47%；标准DiT由2.58%改善至18.21%，仍落后U形模型。同步核对坐标转换、评分范围、类别计数与采样设置，明确不同初始化和输入条件对比较的限制。

在路线探索方面，尝试原始LiDAR同步生成占据与参与者的方案，修复异常点云并开展分阶段训练；随后回退并归档该路线，恢复语义占据、冻结VAE及标注派生参与者输入。进一步完成密集历史与mask_lidar各1万步的匹配训练及评测，平均mIoU分别为27.89%和27.96%，未观察到密集历史的整体提升。

近期，针对其他平坦区域的输入缺失，实现保守历史地面补全，训练子集重建略有改善，未来预测收益仍待验证。同时制作35页汇报PPT、PDF、讲稿和总体流程图，整理实验档案，并评估四卡V100迁移条件。多随机种子、参与者独立消融、反事实响应、风险校准及闭环规划实验尚待完成。
